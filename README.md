This project focuses on systematic data preprocessing and pipeline design for an employee job change prediction problem. Using a real-world dataset, it addresses common data challenges such as missing values, mixed feature types, high-cardinality categorical variables, skewed distributions, and class imbalance. The project implements feature-specific preprocessing pipelines, evaluates the impact of SMOTE and PCA, and compares model performance using Logistic Regression and Random Forest, highlighting how preprocessing choices directly influence predictive performance.# data-preprocessing-using-python
